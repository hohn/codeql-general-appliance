Introductory guide

Begin with the CGA overview: the appliance, a fixed Sample 05 worked example, and installation. Use CGA help for tasks and commands. The outlines below are further usage routes, not prerequisites for that first example.

This is a navigable outline for simpler usage guides, ready for expansion. The linked pages contain core commands and brief descriptions, not completed tutorials. They assume cga and the required tools are installed; see installation and CLI installation.

This repository is an experiment/prototype. Work with databases and queries, inspect what happens, and evolve examples and supporting code together.

The Bench outline follows the existing Bench documentation closely. Bench consumes prepared databases; it does not build them. The shell workflow makes preparation and analysis separate, explicit activities.
