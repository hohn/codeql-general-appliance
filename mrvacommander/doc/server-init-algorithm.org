1.  if not TryAdvisoryLock(73002): return

** Algorithm 12a: Termination conditions
:PROPERTIES:
:CUSTOM_ID: alg12a
:END:

The worker exits the loop (step 10) on exactly two conditions:

1. *Drain signal*: pool manager sets worker status to =Draining= in DB;
   worker sees it on next poll.
2. *Idle timeout*: no job claimed for T_{idle} (default 300s).
   Timer resets each time a job is successfully claimed.

After exiting, the worker marks itself =Exited= (step 11) and the process
terminates.  If the process crashes instead (no =Exited= written), the
pool manager's =reapDeadWorkers= ([[*Algorithm 9: =reapDeadWorkers=][Alg 9]]) detects the stale heartbeat and
requeues the in-flight job.
