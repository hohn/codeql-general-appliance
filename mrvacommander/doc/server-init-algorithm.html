12. Algorithm 11: pollArgoStatuses — reconciliation

Source: pkg/pool/pool.go:370-473 

1.  if not TryAdvisoryLock(73002): return
2.  jobs <- S.GetRunningJobs() ++ S.GetQueuedJobs() with ArgoWorkflowID
3.  for each job:
        phase <- W.GetWorkflowStatus(job.ArgoWorkflowID)
        if error and startedAt < 60s ago: skip  -- startup lag
        if error and startedAt >= 60s:    phase <- "Error"
        reconcile(job, phase):
            if phase in {Succeeded, Failed, Error}:
                S.SetStatus(job, mapPhase(phase))
                S.SetJobInfo(job, {CompletedAt: now})
            if phase in {Running, Pending}: no-op

13. Algorithm 12: Agent main() — pool mode worker

Source: agent-commander-argo/main.go

Uses: Alg 13, Alg 14 

Input : env (no --job flag)
Output: worker loop, exits on idle or drain

 1.  wID <- hostname-rand()
 2.  T_{poll} <- env or 2s;  T_{idle} <- env or 300s;  T_{hb} <- env or 10s
 3.  S <- NewPGState()
 4.  Q <- InitRabbitMQResultsOnly()       -- publish results only
 5.  A <- InitMinIOArtifactStore()
 6.  D <- InitHEPCDatabaseStore()
 7.  S.RegisterWorker(wID, podName)
 8.  go heartbeat(T_{hb}):
         loop: S.WorkerHeartbeat(wID)     -- update heartbeat_at
 9.  t_{idle\_start} <- now()
10.  loop:                                                  [Alg 12a]
         if S.GetWorkerStatus(wID) = Draining: break
         job <- S.ClaimJob(wID)                             [Alg 13]
         if job = nil:
             if now() - t_{idle\_start} > T_{idle}: break   -- idle exit
             sleep(T_{poll}); continue
         t_{idle\_start} <- now()                            -- reset
         S.SetWorkerBusy(wID, jobKey)
         result <- agent.RunAnalysisJob(job, A, D)          [Alg 14]
         if err: S.CompleteJob(wID, job, Failed)
         else:   S.CompleteJob(wID, job, result.Status)
                 Q.PublishResultSync(result)
         S.SetWorkerIdle(wID)
11. S.SetWorkerStatus(wID, Exited)

13.1. Algorithm 12a: Termination conditions

The worker exits the loop (step 10) on exactly two conditions:

  1. Drain signal: pool manager sets worker status to Draining in DB; worker sees it on next poll.
  2. Idle timeout: no job claimed for Tidle (default 300s). Timer resets each time a job is successfully claimed.

After exiting, the worker marks itself Exited (step 11) and the process terminates. If the process crashes instead (no Exited written), the pool manager's reapDeadWorkers (Alg 9) detects the stale heartbeat and requeues the in-flight job.

14. Algorithm 13: ClaimJob — atomic job acquisition

Source: pkg/state/state_postgres.go:1027-1094 

Input : wID
Output: job or nil

1.  BEGIN tx
2.  SELECT (session_id, owner, repo) FROM job_status
       WHERE status = Queued
       ORDER BY session_id, owner, repo
       LIMIT 1
       FOR UPDATE SKIP LOCKED              -- concurrent-safe
3.  if no row: return nil
4.  UPDATE job_status SET status = InProgress
5.  UPDATE job_info   SET worker_id = wID, started_at = NOW()
6.  SELECT payload FROM analyze_jobs
7.  COMMIT
8.  return unmarshal(payload)
