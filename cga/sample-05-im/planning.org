** Abstract Description
  - These points refer to cga/sample-05-i. cga/sample-05-i is not to be changed;
    This tree, cga/sample-05-im, can copy as needed.

  - Problem: cgast state propagation in single-machine-mrva/cga gets complex when
    applied to multi-run scenarios; branching and tracking state needs to be
    addressed.

  - For cga, the docs state:
    Because stdout is only the CGAST, the components pipe together:
    #+BEGIN_SRC sh 
      submitted=$(
        echo '{}' \
          | cgadl getmeta db-collection.global/metadata.sql \
          | cgadl select --user demo primary_language cpp \
          | cgadl download --output-dir "$MRVA_DB_SERVE_DIR" \
          | cgaql index ../sample-query \
          | cgaql select --user demo language cpp \
          | cgaql pack \
          | cgamr submit --name demo-1 --user demo --language cpp
      )
    #+END_SRC

  - The cgast flows though a pipe; if we consider intermediate states and
    operations, we have, for example,
    : cgadl < st01 > st02
    : cgaql < st02 > st03
    : cgamr < st03 > st04
    In data flow form, this is just a chain / linked list
    : st01 -> cgadl -> st02 -> cgaql -> st03 -> cgamr -> st04

    #+HEADER: :file cga-chain.svg :exports results :results file
    #+BEGIN_SRC dot
      digraph chain {
        rankdir=LR;
        node [fontname="monospace"];
        node [shape=ellipse]; st01; st02; st03; st04;
        node [shape=box];     cgadl; cgaql; cgamr;
        st01 -> cgadl -> st02 -> cgaql -> st03 -> cgamr -> st04;
      }
    #+END_SRC

  - In actual use, there will be more than one chain.  We can have multiple
    parallel chains, or even subtrees.
    Thus, the flow topology is more complex.
    let the numbered arguments to cga* denote distinct parameters.

    - The parallel case 
      : st01 -> cgadl 0 -> st02 -> cgaql 0 -> st03 -> cgamr 0 -> st04
      : st11 -> cgadl 1 -> st12 -> cgaql 1 -> st13 -> cgamr 1 -> st14
      : st21 -> cgadl 2 -> st22 -> cgaql 2 -> st23 -> cgamr 2 -> st24
      : st31 -> cgadl 3 -> st32 -> cgaql 3 -> st33 -> cgamr 3 -> st34
