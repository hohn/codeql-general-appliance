# CodeQL C/C++ path queries

These query entry points are copied from the installed CodeQL CLI 2.23.9 C/C++
query pack so the CVE samples have stable, local query references.

The authoritative upstream sources are in the
[GitHub CodeQL repository](https://github.com/github/codeql/tree/codeql-cli/v2.23.9/cpp/ql/src).
Each CVE README identifies the applicable query ID and local file.

Sibling `.qll` support modules required by an entry point are kept beside it.
`cgaqg materialize` and `cgaql pack` preserve those modules with the query.
