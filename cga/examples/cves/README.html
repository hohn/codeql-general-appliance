C/C++ path-problem CVE catalogue

This catalogue contains 60 verified Debian CVEs whose vulnerability class is represented by an installed CodeQL C/C++ @kind path-problem query. Every sample records vulnerable, fixed, and current Debian source versions and stages all three source packages without building them.

The machine-readable research result is catalogue.json. Regenerate sample metadata with ./generate.py; download every source set with ./download-sources.py.

The large, critical per-CVE tmp workspaces live outside Git under /mnt/common/home/hohn/work-ghp/single-machine-mrva-artifacts/examples/cves/. Each populated sample has an ignored relative tmp symlink to its corresponding external workspace, so existing scripts and documented paths continue to work. The external artifact root contains content and symlink-target manifests whose hashes are anchored by cga/analysis/ARTIFACTS.sha256.

The shared query files under queries/ are copied from the installed CodeQL 2.23.9 C/C++ query pack. Each sample links to its exact query and records the query ID in spec.json.
