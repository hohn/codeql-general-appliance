# AGENTS

**Read the [agent core](.agent-notes/README.md) first.** For CGA work, then use
the [LLM exploration guide](docs/cga-help-llm.org) and select one task route.
For other work, choose only the matching topic from the core.

Read the relevant help, current-state projection, and named contract section
before opening the owning component's files. Stop expanding context when the
task is answerable; linked documents are not a mandatory reading list.
Use the [advanced project map](READING-GUIDE.md#reading-paths) only if the
focused route and component-local investigation cannot identify the owner.
Do not begin with the whole-repository README, generated help HTML, or a
recursive repository scan.

This repository is a science experiment/prototype. Evolve code, examples, and
usage explanations together. Retain examples for experimentation; e2e tests are
fixed examples that test code. Remove obsolete documentation rather than
archiving it.

Keep the core short and update the matching topic notes as conventions change.
